# 第 5 章笔记：Writing the Discussion/Conclusion

## 逆向模型（Introduction 镜像）
① 回访: 已有研究+局限 → 你的方法 → 你的结果
② 定位: 你的工作在研究地图上的位置
③ 成就: 意义 + novelty + 应用
④ 局限 → 未来工作

## 情态动词校准表
- 无 = 实证事实（有证据）
- can = 能力
- may/might/could = 可能（might 弱于 may）
- should/ought to = 很可能 或 建议（双义，用前想清楚）
- must/have to = 几乎确定但没证据 或 必要
- **must 悖论**: "It must be ten o'clock" 是没戴表时说的 → must 暴露证据缺口
- 过去式: may/might/could have（没有 can have）

## 否定陷阱
- must not = 禁止 ≠ doesn't have to = 不需要
- cannot = 不可能 ≠ can not = 可能不
- could not have been = 不可能是（过去）

## 局限的艺术
- 局限 = 未来研究的门（可解决的才提）
- 正面配对: "Although our hypotheses were supported statistically, the sample was not..."
- therefore 连接: "Future work should therefore include..."
- 具体化: ✗ "could explore further" ✓ "evaluate whether X is retained in the long term"

## GOR Discussion 示范要点
- novelty: "this is, to our knowledge, the first framework to..."
- 推断用 may: "may serve as a reliable directional signal"
- 建议用 should: "position sizing should be conservative"
- 局限全部带门: 样本小→扩大回测 / VIX阈值单次校准→更多事件 / 日频→盘中
