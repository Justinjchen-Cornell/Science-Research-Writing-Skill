# 第 1 章笔记：核心方法论

## 核心观点
科学写作是高度套路化的：固定结构 + 有限词汇 + 少量语法（时态/被动）。
不需要学更多英语，需要学"模式 + 词汇"。

## 方法：Examine → Identify → Apply
1. EXAMINE：收集 3-4 篇领域内真实论文（目标论文）
2. IDENTIFY：标记每句话"在做什么"（功能，不是内容）
3. APPLY：用模型 + 词汇写自己的段落

句子功能识别技巧：想象句子被删除，读者失去什么？
（类比：投资案例的"结构"可迁移，"内容"不可迁移）

## 三问法（每章骨架）
1. 怎么写开头？
2. 放什么信息、什么顺序？
3. 怎么结尾？

## 对称漏斗结构
- Introduction：general → specific（收窄）
- Discussion：specific → general（放宽，与 Intro 镜像）
- 写作顺序：Methods → Results → Intro → Discussion → Abstract → Title

## 目标论文五标准
1. 英语国家机构作者（最好母语者）
2. 短（<15 页含图表）
3. 主题接近
4. IMRD 四段结构清晰
5. 不用书本章节当目标

## 案例：PLA 引言 10 句功能
1-3 建立重要性+背景 → 4 问题领域 → 5 过渡 → 6 文献 → 7 空白(However) → 8-10 本文

## 投资类比
论文结构 = 投资备忘录结构（行业→尽调→发现→判断）
→ PE 投资人学这本书有天然优势
