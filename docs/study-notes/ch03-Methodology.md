# 第 3 章笔记：Writing about Methodology

## 四部件菜单模型（按需选，不是必用）
① 总览 + 重述目的 + 材料/设备来源 + 必要背景
② 具体细节（数量/温度/时长/顺序/条件）+ 论证选择 + 表明细心
③ 与其他研究的关系（方法引用）
④ 指出问题（如有，最小化语言）

## 核心规则：被动语态时态切分（最重要）
- Present Simple passive (is done) = 标准流程 / 设备常态
- Past Simple passive (was done) = 你自己干的活
- 被动不带施动者 → 读者只能靠时态区分 → 混淆 = 你的贡献消失 = 灾难
- 书例: "The pulses WERE split into reference pulses" —— 唯一的 Past Simple = 作者创新点

## 标记双保险
- In this study, the samples were collected... / In our experiments...
- 引用他人: In Brown (1999) the samples were collected...

## a/the 规则
- THE = 你和读者都知道指哪个（共享知识: the check-in / the flame / the keyboard）
- A = 哪个都行 / 不知道 / 读者不知道
- 单数可数名词必须有冠词
- a/an 按发音: an MRI scan / a UV light
- 三个都可用作泛指（The/An/复数）

## 副词安全
- 副词位置错误 = 隐形错误（语法对但意思错，编辑看不出）
- "The lecture on cancer in January" ← 歧义
- 整句副词放句首；避免副词簇；歧义就重写

## GOR Methodology 成品（可迁移句式）
- "The system described in this study was constructed from [数据源]"
- "GOR is calculated as... and a four-tier threshold table is applied to..."
- "A dynamic hard stop-loss rule (v2.1) was introduced to replace [旧规则], after [旧规则] was shown to be overly conservative during [事件]"
- "The [阈值] are consistent with the historical equilibrium range documented in prior studies"
- "Data availability is a limitation: [问题], and [解法]"

## 时态切分示范（GOR 版）
- was constructed / was introduced = 你的两件大事（Past Simple）
- is calculated / is applied / is triggered / is overridden = 系统常态（Present Simple）
- 读者扫时态 = 定位你的贡献
