# 📐 Book Study Template — 把任何一本书变成一套可执行的学习笔记

> 从《Science Research Writing》学习实战中提炼的模板包。目标：**任何一本书，用同一套结构，产出"能学会 + 能实战"的学习笔记。**
> 用法：复制本目录 → 填 `[占位符]` → 按流程产出。

## 核心流程（4 步，每本书通用）

```
STEP 1  解剖书（30min）
  读目录 + 序言 → 判断书类型 → 定章节边界（5-9 章为宜）
    ↓
STEP 2  建地图（10min）
  填 00-学习地图 → 7 章路线图 + 进度追踪
    ↓
STEP 3  逐章产出（每章 1-2h）
  用 chNN 模板：目标 → 核心框架 → 案例拆解 → 贴读者案例 → 实战示范 → 练习 → 自查
    ↓
STEP 4  实战闭环（2-3h）
  用书中模型写一篇"实战作品"（论文/方案/决策报告）
  用 素材标注 练功能识别
  每章产出的可迁移句式汇入 句式库
```

## 书类型适配（决定每章侧重）

| 书类型 | 章节侧重 | 实战产出示例 |
|:--|:--|:--|
| **方法论/技能型**（如本书） | 模型部件 + 语言/规则系统 + 案例 | 用模型写一篇完整作品 |
| **思维模型型**（芒格/塔勒布） | 框架命名 + 心智模型 + 反模式 | 用框架分析一个真实决策 |
| **操作手册型** | 步骤清单 + 检查项 + 陷阱 | 按步骤做出一份产出物 |
| **行业分析型**（投资/尽调） | 分析维度 + 判断标准 + 案例 | 写一份完整分析报告 |

## 质量门槛（每本书验收标准）

- [ ] 学习地图：章节边界清晰（5-9 章）
- [ ] 每章：模型/框架命名保留作者原词（不擅自改）
- [ ] 每章：至少 1 个案例拆解 + 1 个贴读者领域的案例
- [ ] 每章：练习 + 自查清单（读者能自测）
- [ ] 实战闭环：1 篇完整实战作品（不是摘要，是成品）
- [ ] 句式库：从书中提炼 ≥5 条可迁移句式（实战时复用）
- [ ] 版权：不含原文大段摘录，注明出处

## 与 book-to-skill 的分工

| 工具 | 产出 | 用时 |
|:--|:--|:--|
| **book-to-skill** | SKILL.md + 章节摘要（给 AI 用的工具）| 1-2h |
| **本模板** | 学习笔记 + 实战作品（给人学的课程）| 3-5 天 |
| **审判卡（100本书系列）** | 300 字判决书（给市场的产品）| 1-2h |

三者共用同一本素材，产出不同形态 —— 这就是「100本书审判」的流水线。
